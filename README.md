# 创想云签到 · 青龙面板订阅

> [创想云国内模型站](https://www.crealitycloud.cn) 每日签到自动化：
> **账号（手机号 / 邮箱）+ 密码登录 → 每日签到（连续签到 / 累计积分）→ 中文报告推送**
>
> 单文件 · 零依赖（仅 Python 标准库 `urllib`）· 多账号 · 无需安装桌面端

---

## ✨ 功能特性

- ✅ **账号密码登录**：走官方统一账号中心 `id.creality.cn`（OAuth 体系），手机号自动补 `+86` 区号，邮箱直接识别
- ✅ **每日签到**：`checkinV2` 接口，自动判断是否已签到，提取连续签到天数与奖励
- ✅ **双路径降级**：内置「直接登录态签到 → OAuth 授权码换取」双路径，token 不通用时自动切换，兼容性更强
- ✅ **多账号**：每行「账号 密码」，多账号换行分隔，顺序执行
- ✅ **幂等安全**：先查签到状态，已签到则跳过，不重复提交
- ✅ **通知推送**：自动对接青龙面板 `notify.py`，运行结束推送中文报告

## 🚀 快速开始（青龙三步）

### 1. 上传脚本

- **方法一、📌 订阅仓库**：在青龙「订阅管理」中添加订阅，拉取脚本仓库后，脚本自动出现在脚本管理中。
- **方法二、上传脚本**：将 `crealitycloud_checkin.py` 上传到青龙面板「脚本管理」。

### 2. 配置账号

在青龙面板「环境变量」中新增：

| 变量名 | 说明 |
|--------|------|
| `CREALITY_ACCOUNTS` | 账号密码列表：**每行「账号 密码」（账号与密码用空格分隔），多账号换行分隔** |

示例（环境变量 `CREALITY_ACCOUNTS` 的值）：

```text
13800138000 密码1
email@example.com 密码2
```

> 也可不改环境变量，直接编辑脚本顶部 `CONFIG_ACCOUNTS` 内置配置（格式相同）。

### 3. 创建定时任务

| 项目 | 值 |
|------|-----|
| 任务名称 | 创想云签到 |
| 命令 | `task crealitycloud_checkin.py` |
| 定时规则 | `0 9 * * *`（每天 09:00 执行） |

完成。

## 📋 账号格式说明

| 类型 | 填写示例 | 说明 |
|------|----------|------|
| 手机号 | `13800138000` | 自动补 `+86` 区号；也可直接填 `8613800138000` |

## 🔧 接口说明（供维护参考）

| 步骤 | 接口 | 说明 |
|------|------|------|
| 登录 | `POST https://id.creality.cn/api/cxy/account/v2/loginV2` | 账号密码登录，`type=1` 手机 / `type=2` 邮箱 |
| 签到 | `POST https://api.crealitycloud.cn/api/cxy/v2/task/checkinV2` | 认证 header `__CXY_TOKEN_` / `__CXY_UID_` |
| 状态 | `POST https://api.crealitycloud.cn/api/cxy/v2/task/getLastCheckin` | 最近签到状态 |

- 国内站 `clientId`：`8ea5010984fa52a298f12110af8b05d0`
- 登录中心请求头 `__CXY_APP_ID_`：`creality_account`
- 主站请求头 `__CXY_APP_ID_`：`cxy-gen2`

## ❓ 常见问题

**Q: 提示「未配置账号」？**
未设置环境变量 `CREALITY_ACCOUNTS`，脚本内 `CONFIG_ACCOUNTS` 也未填写。按上文「配置账号」步骤填写即可。

**Q: 登录失败提示 `code=9`（账号未注册）或密码错误？**
核对账号与密码；手机号会自动补 `+86` 区号，确认手机号本身无误。

**Q: 提示 `code=4`（token 非法）？**
脚本会自动切换 OAuth 授权码方式重试；若仍失败，可能是登录态过期，可稍后重跑。

**Q: 频繁执行会怎样？**
频繁异常登录可能触发平台风控，建议保持每天一次（`0 9 * * *`），不要设置过高频率。

## 📄 错误码速查

| code | 含义 |
|------|------|
| 0 | 成功 |
| 1 | 参数错误 |
| 4 | Token 无效 |
| 5 | 身份无效 |
| 9 | 账号不存在 |
| 35 | 用户被封禁 |
